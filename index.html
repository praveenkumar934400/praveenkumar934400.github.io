Projects

EB Bill System

An electricity bill calculator that remembers every reading

You enter a service number and the units used. The server works out the bill slab by slab, saves it, and refuses to read the same service number twice. A separate summary page shows the totals.

  • Five price slabs, from free up to 200 units to ₹7 per unit above 500.
  • Service numbers must be 9 to 12 digits, checked in the browser and again on the server.
  • Readings are saved in a JSON file, so they survive a restart.
  • Summary page with totals, average, highest bill, and units by slab.
  • Written only in TypeScript. No build step: npm start runs it.
